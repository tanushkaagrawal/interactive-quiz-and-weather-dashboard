# Interactive Quiz & Weather Dashboard

## 📌 Project Description

Interactive Quiz & Weather Dashboard is a web-based project that combines an interactive quiz application with a real-time weather dashboard in a single user-friendly interface.

The quiz section allows users to answer multiple-choice questions, receive instant feedback, and view their final score. The weather dashboard allows users to search for a city and view current weather information such as temperature, weather conditions, humidity, and wind speed.

The project was developed to practice frontend web development and API integration using HTML, CSS, and JavaScript.

## ✨ Features

### 🎯 Interactive Quiz

* Multiple-choice questions
* Interactive answer selection
* Instant correct/wrong answer feedback
* Automatic score calculation
* Final score display
* Restart quiz option

### 🌤️ Weather Dashboard

* Search weather by city name
* Real-time weather information
* Temperature display in Celsius
* Weather condition display
* Humidity information
* Wind speed information
* Weather icons based on weather conditions
* Error handling for invalid city names

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* OpenWeatherMap API

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `script.js`.
4. Add your OpenWeatherMap API key.
5. Save all the files.
6. Open `index.html` in a web browser.

## 🌐 API Used

The Weather Dashboard uses the **OpenWeatherMap API** to fetch real-time weather information based on the city entered by the user.

## 🎯 Project Objective

The main objective of this project is to develop a practical web application that demonstrates frontend development concepts, JavaScript programming, DOM manipulation, event handling, and API integration.
